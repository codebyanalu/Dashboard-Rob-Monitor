# Dashboard de Atuação e Escrituração Fiscal

Dashboard desenvolvido para acompanhamento e análise operacional das notas fiscais tratadas via monitoramento, permitindo maior visibilidade sobre o processo de atuação e escrituração fiscal.

## Objetivo

Centralizar informações relacionadas às notas fiscais monitoradas, acompanhando o fluxo operacional, produtividade e status das escriturações.

## Funcionalidades

- Acompanhamento das notas tratadas
- Monitoramento das escriturações realizadas
- Indicadores operacionais
- Análises diárias de atuação
- Identificação de pendências e inconsistências
- Comparativos por período

## Tecnologias Utilizadas

- Power BI
- Linguagens de Marcação
- Excel / CSV

## Finalidade

Auxiliar no controle operacional e fiscal, fornecendo indicadores para acompanhamento das atividades realizadas e apoio na tomada de decisão.
